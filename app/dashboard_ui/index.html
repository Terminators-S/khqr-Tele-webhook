Verify every payment event before fulfillment

1
X-KHQR-Event-IDStore processed event IDs and ignore duplicates. Delivery is at-least-once.
2
X-KHQR-TimestampReject stale requests outside your replay window.
3
X-KHQR-SignatureExpected format: v1=<hex HMAC-SHA256>.
signed = HMAC_SHA256(
  WEBHOOK_SECRET,
  X_KHQR_TIMESTAMP + "." + RAW_REQUEST_BODY
)

constant_time_equal(
  "v1=" + hex(signed),
  X_KHQR_SIGNATURE
